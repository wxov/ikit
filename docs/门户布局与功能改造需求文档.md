# i-kit 门户布局与功能改造需求文档

> 版本：v0.2（as-built）
> **本文档说明**：第 1–13 节为参考站分析与需求设计；**§14「现状总览」为当前实际实现记录（以代码为准）**。其他历史文档（PRD / 插件系统需求）中的现状说明同样以此为准。
> 范围：**只改布局 + 只增功能**；保留本项目全部既有功能（知识库 / AI Agent / 插件商店 / 系统 / 用户管理 / 数据统计 / 便签 / 日历 / 待办 / 天气 / RSS / Markdown 剪贴板等）。
> 前置约束（已落实）：登录改为「点击头像弹登录框」，注册已屏蔽（站主手动建号）。完成前不自动提交/部署。

---

## 1. 背景与目标

当前 i-kit 的前台是「控制台 / 面板」形态：顶部导航 + 主区切换 + 移动端底部 Tab。用户希望参考**某知识门户站点**（Typecho 主题风格）的**三栏门户式布局**，把既有功能包裹成更接近「内容站点 / 知识门户」的体验，并借鉴其特色功能。

**坚持的原则**
- 既有功能一个都不删，只调整呈现方式与入口。
- 新增功能与布局改造分开推进，先文档、后分层实施。
- 站主（admin）功能与普通用户（前台）功能保持隔离。

## 2. 参考站布局与功能分析

> 依据浏览器实测（截图 + DOM）。该参考站采用 Typecho 博客主题，核心形态如下。

### 2.1 整体结构：三栏门户
```
┌─────────────────────────────────────────────────────────┐
│ Header：Logo + 站名 | 快捷入口(小店/FRP/RSS/TG群/仓库)     │
│          | 全局搜索(Ctrl+K) | 右上角头像                   │
├──────────┬────────────────────────────┬──────────────────┤
│ 左侧导航  │     主内容（卡片流 feed）      │   右侧 widget 列  │
│ - 站签名   │  - 封面大图卡片，标题叠加     │  - 热门文章       │
│ - 分类树   │  - 摘要 / 作者/时间/浏览/标签 │  - 最新评论       │
│ - 专栏/专题 │  - 分页                    │  - 动态日历       │
│ - 页面链接  │                            │  - 统计图表(雷达/柱状)│
│ - 快捷链接  │                            │  - 标签云         │
└──────────┴────────────────────────────┴──────────────────┘
                        页脚
```

### 2.2 关键布局特征
1. **顶栏**：左 Logo+站名；中间一组快速功能入口（小店/FRP/RSS/TG群/仓库 等外链按钮）；**全局搜索**（占位「搜索（Ctrl + K）」）；极右**头像**（本布局用于登录/个人中心）。
2. **左栏**：竖向导航。顶部一句博主签名 moto；下方是**多级分类树**（如 分类 → 日常资讯/数字生活/运维部署/技术教程/群晖专栏，专栏再分 基础/网络/套件/高级）。再往下是「页面」组（留言板 / 归档库 / 关于我）和「快捷入口」（小店/FRP/RSS/仓库）。
3. **中栏**：**卡片流**。每条卡片 = 封面大图（标题压图、渐变遮罩）+ 正文标题 + 摘要 + 元信息（作者 / 时间 / 浏览数 / 标签 / 分类）。鼠标悬停有位移/阴影动效；底部为分页。
4. **右栏**：**widget 堆叠**。热门文章、最新评论、动态日历、博主发布/评论月统计、**分类雷达图**、**发布统计图**、标签云。整体可折叠。
5. **响应式**：窄屏时左/右栏收起为抽屉，主内容单列。

### 2.3 可借鉴的「功能点」
来自实测提取：
- 多级分类导航（分类树、专栏/专题分组）
- 卡片式内容流（封面 + 标题压图 + 摘要 + 元信息）
- 全局搜索（支持 Ctrl+K 呼出）
- 阅读/浏览计数（"N 次浏览"）
- 热门文章 widget、最新评论 widget、标签云
- 动态日历 widget（近月发布热点日历）
- 统计图表 widget（分类雷达图、发布柱状图、近 10 月发布/评论统计）
- 「专栏/专题」策划（类似知识库的专题合集）
- 页面链接：留言板、归档库、关于我
- 站签名 moto、博主形象位（左栏头像/签名）
- 分页、文章作者/时间/标签元信息排版

## 3. 现状盘点（i-kit 已有）

| 模块 | 现状 | 归属 |
|---|---|---|
| 知识库 | CRUD / 混合检索 / 分类树 / 回收站 / 置顶 / 导出 / 版本 / AI 摘要 / 评分 / 点赞 / 分享 / 状态 | 功能插件 `knowledge` |
| AI Agent | 工具 + RAG + SSE 流式对话 | 功能插件 `agent` |
| 插件商店 | 浏览/安装/更新/卸载/评分/评论；**签名状态徽标**（已验证 / 已签名·装机时验证 / 未签名 / 验签失败，`enforce` 下按钮禁用并给出原因） | 站主 `store` |
| 插件管理 | 启用/停用/配置 | 站主 `manager` |
| 系统 | 系统信息/更新/健康 | 站主 `system` |
| 用户管理 | 列表/角色/重置/禁用（**尚无站主手动加号**） | 站主 `users` |
| 数据统计 | 汇总计数 | 功能插件（商店）`stats` |
| 便签 / 日历 / 待办 / 天气 / RSS / MD剪贴板 | 独立功能面板 | 功能插件（商店） |
| 登录/注册 | AuthPanel（登录+注册+找回） | 全局 |

**当前布局**：单行顶栏（仅 admin 有「管理」下拉分组）+ 主区切换 + 移动端底部 Tab。非站主默认落第一个功能插件。

## 4. 总体改造方向

把「前台功能区」从「控制台」升级为「**知识门户**」三栏布局，站主管理收敛到独立的后台/分组；登录走头像弹框。

```
新前台（普通用户 / 站主皆可见）
├── 顶栏：Logo+站名 | 快捷入口 | 全局搜索(Ctrl+K) | 头像(登录弹框) | 暗色切换
├── 左栏：我的/知识库/Agent/… 功能插件导航（分类树化） + 页面(归档/关于/留言)
├── 中栏：知识卡片流（默认 tab）+ 具体功能面板（Agent→对话流、统计→卡片、便签…）
└── 右栏：热门文章 / 最新评论 / 标签云 / 动态日历 / 统计图表（widget 化）

站主后台（仅 admin，独立分区）
├── 系统 / 插件管理 / 插件商店 / 用户管理（保留现有，入口收敛）
```

**关键点**：功能插件（knowledge/agent/stats/notes/…）仍是 `tab` 切换的主体；「知识库内容」以参考站卡片流当作中栏**默认首屏**；RSS/天气/日历等面板可同时作为右栏 widget 复用来丰富门户。

## 5. 布局改造需求

### 5.1 顶栏 Header
- 左侧：Logo + 站名「i-kit 控制台」→ 可预留「i-kit」品牌位 + 标语位。
- 中间：快捷功能入口（原有功能插件可平铺，或以「更多」收敛）——对应参考站的外链快捷入口位。
- 全局搜索框（占位「搜索（Ctrl + K）」）：回车弹出/聚焦后触发**知识库检索**，命中卡片流。
- 极右：**头像**（登录后显示头像+用户名缩略，点击弹出登录/账号菜单）→ 点击弹出**登录弹框**；未登录时为占位头像（也点开登录框）。暗色切换按钮保留。
- 移除原来顶栏直接堆叠的「system/manager/store/users」管理按钮（已收敛为「管理」分组，且仅在 admin 显示）。

### 5.2 左侧导航栏（桌面）
- 顶部：博主/站主签名 moto 位（可放一句话或站主昵称）。
- 分类/功能树：
  - 「知识库」展开 = 知识分类树（`CategoryTree`），点击分类 → 中栏按分类过滤卡片流。
  - 功能插件（Agent / 数据统计 / 便签 / 日历 / 待办 / 天气 / RSS / MD 剪贴板 …）作为同级导航项。
  - 「专栏/专题」：把部分内容策划成专题合集（可选，二期）。
- 「页面」组：归档库、关于我、留言板（见功能新增）。
- 站主专用（仅 admin）：系统 / 插件管理 / 插件商店 / 用户管理，位于底部，与普通功能**明显分隔**。

### 5.3 主内容区
- **默认首屏**：知识卡片流（复用参考站卡片：封面图 + 标题压图 + 摘要 + 作者/时间/浏览/标签/分类 + 分页）。
- 其它 tab：保留现有功能面板（Agent 对话流、统计信息、便签、日历、待办、天气、RSS、MD 剪贴板）。
- 顶部保留面包屑/当前分类标题 + 排序（最新/最热）+ 搜索过滤状态。

### 5.4 右侧 widget 栏（桌面）
- 热门文章（按浏览量/评分排序，点击定位卡片）
- 最新评论（知识库条目最新评分/评论）
- 标签云
- 动态日历（近 N 月有更新的日期高亮）
- 统计图表：分类雷达图 / 发布柱状图 / 近 10 月发布-评论趋势

### 5.5 响应式
- ≤768px：左右栏收起为抽屉/底部 Tab，主内容单列（保留现有底部 Tab 逻辑，但按新导航分组）。

## 7. 登录与账号调整

- **入口**：点击顶栏**头像** → 弹出登录框（复用 `AuthPanel` 视觉，改成弹窗而非整页/整栏）。
- **注册**：AuthPanel **隐藏注册 tab**，保留 登录 / 找回密码 两个入口。
- **新增用户方式**：站主登入后到「用户管理」→「添加用户」，填 用户名/密码/昵称/角色 → 由后端创建。后端 `register` 接口可保留但前端不暴露；或后端加 `adminCreateUser` 受 `requireAdmin` 保护。
- **登录态呈现**：头像 + 用户名 + 角色徽标；下拉菜单含「退出登录」。

## 8. 保留不变项

以下既有能力**不改语义、仅换入口/布局**：
- 知识库：CRUD、混合检索、分类、回收站、置顶、导出、版本、AI 摘要、评分、点赞、分享、状态。
- AI Agent：function-calling + RAG + SSE 流式。

- 系统监控、用户管理（角色/重置/禁用）、数据统计。
- 便签 / 日历 / 待办 / 天气 / RSS / MD 剪贴板功能面板。
- 暗色模式、三端（Web / Tauri / Capacitor）兼容。

## 10. 数据与接口影响

- 知识库：增加/复用 **浏览计数** 字段与接口（`GET /api/knowledge/:id` +1 浏览，或独立 `POST /api/knowledge/:id/view`）。
- 统计 widget：复用 `/api/plugins-data/statistics`；若需分类雷达/发布柱状，扩展该统计接口返回分类分布与按月发布数。
- 用户：新增 `adminCreateUser` 受 `requireAdmin` 保护；前端隐藏 register。
- 布局数据：站点 moto / 站名 / 关于我 文案 → 站点配置项（可在系统设置中维护，或抽 `config` 服务）。
- 评论：知识库评分/评论与插件商店评论复用现有能力。

## 11. 实施阶段建议

1. **阶段一优先**：先落地三栏骨架 + 卡片流 + 头像登录 + 屏蔽注册 + 手动加用户。
2. 每阶段完成即：`pnpm --filter @ikit/web build` + `tsc --noEmit` + 后端接口冒烟，再进入下一阶段。
3. 布局组件化：新增 `PortalLayout`（三栏）、`NavTree`（左栏）、`Widget*`（右栏）、`ContentCardFeed`（中栏卡片流）；复用现有 `*Panel` 组件。
4. 完成后按 AGENTS.md 不自动提交/部署，等待用户确认。

## 12. 验收标准（阶段一）

- [ ] 桌面三栏门户布局生效（左导航/中卡片流/右 widget），窄屏退化为单列+底部 Tab。
- [ ] 顶栏含 Logo/站名、快捷入口、全局搜索、头像（点击弹登录框）、暗色切换。

- [ ] 站主可在用户管理添加用户（用户名/密码/角色/昵称）。
- [ ] 知识库首屏为卡片流：封面图+标题压图+摘要+作者/时间/浏览/标签/分类+分页。
- [ ] 既有功能插件（Agent/统计/便签/日历/待办/天气/RSS/MD）经左栏仍可进入。
- [ ] 站主管理（系统/插件/商店/用户）仅 admin 可见且与前台功能分隔。
- [ ] 构建 + 类型检查通过；后端接口冒烟通过（登录、用户新增、知识检索、统计）。

## 13. 风险与注意事项

1. **既有功能不可回归**：改造是「换壳」，功能面板逻辑尽量不动，只调容器与路由。
2. **卡片流数据**：知识库条目未必都有封面图 → 需提供默认占位/渐变色封面。
3. **widget 复用**：日历 widget 可复用商店日历插件的视图组件；避免与主面板重复实现。
4. **三端一致性**：Tauri/Capacitor 下的响应式需一并验证（窄屏抽屉/底部 Tab）。
5. **站主隔离**：任何 new admin 功能都要 `requireAdmin`，前端仅在 admin 渲染。
6. **权限**：屏蔽注册后，新用户只能由站主创建，注意默认角色与密码策略。

- **自动保存**：防抖 2s + 最大等待 10s、**严格串行不并发**、内容未变短路、失败按 1/2/5/10s 退避重试（4xx 不重试）；退避用尽仍脏时由「回到前台（`visibilitychange`）/ 窗口获焦 / 30s 低频定时」再次自动尝试（成功后撤销定时器，4xx 仍不重试，保留手动「保存失败 · 点击重试」）；`blur` / 切标签页 `visibilitychange` / `beforeunload` / 离开编辑态 / `Ctrl/Cmd+S` 均触发落盘；`autosave:true` 的 `PATCH` 跳过 embedding 向量化（发布/撤回不跳过）；localStorage 草稿快照用于刷新/崩溃恢复（非弹窗「恢复 / 丢弃」提示条）。
- **发布 / 撤回**：`PATCH /api/knowledge/entries/:id` 带 `status:'published' | 'draft'` 双向切换；`status:'archived'` 或非法值 → 400；发布前服务端校验合并后的标题与正文均非空（否则 400「发布前需填写标题与正文」）；发布后停留编辑态 + 轻提示。`POST /api/knowledge/entries` 在 `status:'published'` 时套用**同一发布不变式**（标题与正文均需非空白，否则 400），`status:'draft'`（默认）与「标题与正文不可同时为空」的放宽语义不变；导入弹窗「＋新建父文档」的父容器改用 `content:'# <标题>'`（非空白、渲染即标题）以适配该校验。
- **多端联动提示条（AC-24，2026-10-13 第 2 轮收敛口径）**：`knowledge:changed` 命中当前文章时，**仅站主（admin）**显示非弹窗黄条（游客 / 登录非站主完全不提示）；**同一 `updatedAt` 只提示一次**——按文章 id 记录「最近提示过的版本」，值相同的重复广播不再弹、出现新的 `updatedAt` 才再次提示；用户收起（「继续编辑」/「×」）只收条、**保留**版本记录，而切换文章 / 离开详情 / 删除时**重置**记录。阅读态提供「重新载入」（显式拉取最新并按 `id` 替换显示）；编辑 / 新建态只提示（文案「…你的修改仍在保存中」）+「继续编辑」，**永不覆盖正在输入的内容**（全仓无任何 WS→编辑器回写路径）。本端写入（自动保存 / 发布撤回 / 删除）通过 `writing` 打点 + 3s 在途保护窗 + `updatedAt` 指纹抑制自更新回声（服务端广播先于 HTTP 响应到达也不误弹）。
- **他端删除（`remove`）提示**：他端把当前文章软删除（移入回收站）时，阅读态提示「该文章已被删除或移入回收站」+「返回列表」；编辑 / 新建态同文案（追加「你的修改仍在保存中」）+「返回列表 / 继续编辑」（「返回列表」先尽力 flush，失败也不把用户困在编辑态；继续编辑后保存按其自身路径处理，不做额外语义）。
- **可见性与默认状态**：`status='draft'` **仅站主可见**（非 admin 的列表 / 搜索 / 分类计数 / 评论 / 详情 / 浏览计数 / Agent 检索统一过滤；`status` 缺省或 NULL 视为已发布，存量条目不受影响）；开关 `KB_DRAFT_VISIBILITY=admin-only | everyone`（默认 `admin-only`，`everyone` 即回滚为「草稿全员可见」）；批量导入默认 `published`（导入即可见），交互式新建默认 `draft`；导入弹窗「＋新建父文档」显式 `published`（父容器需对游客可见，顺带修复「可见子项因父档不可见而在左栏目录树变孤儿」）。
- **存量迁移**：服务启动时**幂等**迁移——把本功能上线前创建的 `status='draft'` 条目改为 `published`；写前自动备份存储文件为 `<file>.bak-<yyyyMMddTHHmmss>`，幂等标记写在 `KnowledgeDb.meta.draftPublishV1`（SQLite 新 `meta` 表 / JSON 普通键），开关 `KB_MIGRATE_DRAFT_STATUS=publish | off`（默认 `publish`），截止时间常量 `DRAFT_PUBLISH_CUTOFF`（默认 `2026-10-20T00:00:00.000Z`，**发布前需由发布者确认**）；回滚三步：停服 → 还原备份 → `KB_DRAFT_VISIBILITY=everyone` 启动。
- **站主侧读路径补授权**：`App.vue`（分类）/`DocTree.vue`/`ContentCardFeed.vue`/`ArchiveView.vue`/`PortalRight.vue`/`CommentSection.vue` 的知识库 GET 统一补 `Authorization`，否则站主会按游客身份过滤、看不到自己的草稿；卡片流与归档对站主显示「草稿」角标。
- **快捷键**：`Ctrl/Cmd+K` 与 `/` 聚焦全局搜索；`N` 新建文章（仅站主、非编辑态、焦点不在输入控件时）；`Ctrl/Cmd+S` 编辑态立即保存（拦截浏览器保存对话框）；`Escape` 只关下拉菜单（编辑态内不退出编辑，避免误触丢输入）。
- **构建**：`apps/web` 接入 `vue-tsc`（`typecheck` 脚本；`build` = `vue-tsc --noEmit -p tsconfig.json && vite build`）。
- **已知偏差**：`GET /api/knowledge/categories` 的分类**树结构**仍来自全局 `db.categories`（只有 `count` 按可见性统计），故非 admin 仍可能看到「草稿独有分类」的路径（count 0）——本期按方案不改 `getCategories`；移动端/桌面端 `/uploads/...` 相对路径问题为既有缺陷，另立项处理。
