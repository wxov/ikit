## 一、产品定位与目标

- **产品名称**：个人知识库（轻量级 / 本地优先 / 纯个人）

- **核心价值**：为个人提供一个**快速记录、灵活分类、随时查找**的知识管理工具，像"第二大脑"一样轻便可靠。

- **目标用户**：仅限本人（无多用户、无协作、无权限管理）。

- **核心原则**：

  - **极简启动**：打开即写，无需配置。

  - **数据归属**：所有内容属于用户自己，支持本地存储或个人云盘同步。

  - **搜索优先**：找东西比整理东西更重要。

- **技术形态**：Web App（PC/Mobile 自适应） + 可选 PWA（离线可用）。

## 二、功能需求（全部为 P0 核心功能）

### 1. 知识录入

| 功能 | 描述 |

| :--- | :--- |

| **新建文档** | 空白页开始写作，支持 Markdown 语法。 |

| **快速记录（灵感闪念）** | 一个极简输入框（类似备忘录），回车即保存，不强制填写标题。 |

| **导入文件** | 支持导入 `.md.txt` 文件，自动解析为文档内容。 |

| **粘贴网页链接** | 粘贴 URL，自动抓取网页标题和正文内容（可配置是否自动保存）。 |

### 2. 知识组织

| 功能 | 描述 |

| :--- | :--- |

| **分类（文件夹）** | 支持一级分类（或最多两级），用于粗略分组。不强制归类，未归类文档统一在"未分类"下。 |

| **标签系统** | 自由添加/删除标签，支持标签筛选。标签即分类，比文件夹更灵活。 |

| **置顶** | 重要文档可置顶，排在最前面。 |

| **归档** | 不删文档，把暂时不用的内容归档，默认隐藏。 |

### 3. 搜索与查找

| 功能 | 描述 |

| :--- | :--- |

| **全文搜索** | 搜索标题、正文、标签。即时搜索（输入即出结果）。 |

| **搜索高亮** | 搜索结果中高亮匹配关键词。 |

| **按标签筛选** | 点击标签快速筛选出带该标签的所有文档。 |

| **按分类筛选** | 点击文件夹筛选该分类下的文档。 |

| **最近浏览** | 自动记录最近查看的 20 篇文档。 |

### 4. 阅读与笔记

| 功能 | 描述 |

| :--- | :--- |

| **Markdown 渲染** | 标准 Markdown 语法支持（标题、列表、代码块、表格、引用、图片、链接）。 |

| **代码高亮** | 代码块自动语法高亮。 |

| **阅读模式** | 干净、无干扰的阅读界面（居中、大字、自动暗色适配）。 |

| **划线与批注** | 选中文字后可高亮标记，并添加批注（批注与原文关联）。 |

| **阅读进度** | 每篇文章记录阅读进度百分比，下次打开自动跳转。 |

| **阅读时长预估** | 根据字数估算阅读时长。 |

### 5. 数据管理

| 功能 | 描述 |

| :--- | :--- |

| **本地存储优先** | 数据默认保存在浏览器本地（IndexedDB），无需注册登录。 |

| **导出单个文档** | 导出为 `.md` 或 `.pdf`。 |

| **导出全部数据** | 一键导出所有文档的 `.zip` 压缩包（含 md 文件 + 图片附件）。 |

| **导入备份** | 导入之前导出的 zip 包，恢复完整知识库。 |

| **云同步（可选）** | 支持配置 WebDAV（如坚果云、iCloud）进行多端同步（非必需，可后期实现）。 |

### 6. 回收站

| 功能 | 描述 |

| :--- | :--- |

| **软删除** | 删除文档先进回收站，不立即丢失。 |

| **彻底删除** | 回收站中手动清空或逐条彻底删除。 |

| **恢复** | 回收站中的文档可一键恢复到原位置。 |

## 四、核心交互流程

### 1. 记录一个新想法（最快路径）

打开App → 点击"+"（移动端）或"新建文档"（PC）  
→ 出现空白编辑器，光标自动聚焦  
→ 输入内容  
→ 点击"保存"或按 Ctrl+S  
→ 自动取正文前20字为标题（可手动改）  
→ 保存成功，返回列表页

### 2. 搜索知识

点击搜索框 → 输入关键词（实时反馈结果）  
→ 结果列表展示匹配文档（标题高亮）  
→ 点击结果 → 进入阅读页  
→ 如未找到，显示空状态插画 + "去新建一篇"

### 3. 整理知识（打标签 / 移动分类）

在列表页 → 右键点击文档（或长按移动端）  
→ 弹出操作菜单 → 选择"编辑属性"  
→ 弹出侧面板 → 修改分类 / 增删标签 / 置顶 / 归档  
→ 点击确认 → 更新完成

## 五、数据结构设计（极简）

### Document（文档）

| 字段 | 类型 | 说明 |

| :--- | :--- | :--- |

| `id` | string | 唯一ID（时间戳 + 随机数） |

| `title` | string | 标题（未填时自动取正文前20字） |

| `content` | text | 正文（Markdown格式） |

| `category` | string | 分类名称（为空则归入"未分类"） |

| `tags` | array | 标签数组（如 `["技术","AI"]`） |

| `isPinned` | boolean | 是否置顶 |

| `isArchived` | boolean | 是否归档 |

| `isDeleted` | boolean | 是否在回收站 |

| `createdAt` | datetime | 创建时间 |

| `updatedAt` | datetime | 最后修改时间 |

| `readingProgress` | number | 阅读进度百分比（0-100） |

| `wordCount` | number | 字数统计 |

### Annotation（批注/划线）

| 字段 | 类型 | 说明 |

| :--- | :--- | :--- |

| `id` | string | 唯一ID |

| `docId` | string | 关联文档ID |

| `type` | enum | `highlight` 或 `comment` |

| `startOffset` | number | 选中文字起始位置 |

| `endOffset` | number | 选中文字结束位置 |

| `text` | text | 选中的原文片段 |

| `note` | text | 批注内容（如果是comment类型） |

| `createdAt` | datetime | 创建时间 |

## 六、技术选型建议（轻量级）

| 层次 | 技术方案 | 理由 |

| :--- | :--- | :--- |

| **前端框架** | React / Vue（任一） + Vite | 启动快、生态好 |

| **UI 组件** | 无UI库，手写CSS或使用 Tailwind | 保持轻量，避免臃肿 |

| **本地存储** | IndexedDB（Dexie.js 封装） | 存储量大，支持结构化数据 |

| **Markdown渲染** | marked / markdown-it | 轻量且通用 |

| **代码高亮** | highlight.js / prism.js | 标准方案 |

| **搜索** | 纯前端倒排索引（MiniSearch / Lunr.js） | 轻量、无需后端，支持中文分词 |

| **数据导出** | JSZip（打包下载） | 常用库 |

| **WebDAV同步（可选）** | webdav-client | 支持个人云盘备份 |

| **部署** | Vercel / Netlify（前端静态部署） | 免费、快速 |
