## 二、系统总览

### 2.1 一句话技术栈

机器人 + Web 服务 + AI Agent 成套项目：**Cordis 3 插件后端 + Fastify 5 API（REST + WebSocket + SSE）+ Vue 3/Vite 前端**，存储为 JSON（默认）/ SQLite（大数据量切换），部署为 Docker + docker-compose。

### 2.2 模块图

```
┌─────────────────────────────────────────────────────────────┐
│  前端 apps/web（Vue3，三端共用：Web / Tauri 桌面 / Capacitor 移动）│
│  App.vue 门户壳 + components/*（卡片流/目录树/编辑器/评论/Agent/…）  │
└──────────────┬──────────────────────────────────────────────┘
               │ REST /api/*  +  WebSocket /ws  +  SSE
┌──────────────▼──────────────────────────────────────────────┐
│  packages/api（Fastify：路由 + 鉴权 requireAdmin/requireUser + 事件桥）│
└──────────────┬──────────────────────────────────────────────┘
               │ ctx.set 服务调用
┌──────────────▼──────────────────────────────────────────────┐
│  packages/core（Cordis Context 装配 7 内置插件）               │
│  llm · demo · knowledge · agent · plugin-registry · account · store-data │
│  （+ plugin-registry 动态加载 plugins/* 第三方包，如 hello）     │
└──────────────┬──────────────────────────────────────────────┘
               │ 存储
        ┌──────┴───────┐
        │ JSON（默认）  │  SQLite（KB_STORAGE=sqlite，自动迁移）
        └──────────────┘
```

### 2.3 三端关系（摘要，详见 `docs\desktop-mobile.md`）

- 三端共用 `apps\web` 同一套前端 + 同一套 REST/WS 后端；唯一差异是 API 基地址（`apps\web\src\lib\config.ts` 读 `VITE_API_BASE`）。
- Web 端：相对路径（dev 走 Vite proxy，生产同源由 `@fastify/static` 托管 dist）。
- 桌面端：Tauri 2（`apps\web\src-tauri`），构建注入 `VITE_API_BASE=http://localhost:3000`；内含本地 agent 节点。
- 移动端：Capacitor（`capacitor.config.ts`），构建注入局域网 IP。
- WebSocket `/ws` 事件（如 `knowledge:changed`）让三端实时联动。

### 2.4 内置插件清单（`packages\core\src\index.ts:57-71` 装配顺序）

| 插件 | 服务 | 说明 |
|---|---|---|
| `llm` | `ctx.llm` | chat / chatStream（含 tools）/ embed |
| `demo` | `ctx.demo` | 最小示例 + `demo:greeted` 事件 |
| `knowledge` | `ctx.knowledge` | 知识库（CRUD/混合检索/目录/评论/可见性） |
| `agent` | `ctx.agent` | function-calling 运行时 + 会话/节点/任务 |
| `plugin-registry` | `ctx.pluginRegistry` | 插件注册表 + 商店 + 第三方包加载 |
| `account` | `ctx.account` | 账号 + 用户组 + 会话 |
| `store-data` | `ctx.storeData` | 商店插件真实数据（便签/日程/待办/天气/RSS/MD） |

> 另有第三方插件包 `plugins\hello\`（`index.ts` + `plugin.json`），由 `plugin-registry` 的 loader 动态加载，验证第三方插件链路。

### 模块 ① 知识库内容管理（文章 / 目录树 / 分类 / 回收站 / 评论 / 封面 / 浏览计数）

**概述**：知识库是门户的**默认首屏（非插件）**。站主（admin）维护文章，游客按可见性只读，登录用户可评论。数据模型见 `packages\plugins\knowledge\src\types.ts`（`KnowledgeEntry` 字段 `:20-59`）。

**关键需求点（来源文档）**：
- 文章 CRUD + Markdown 渲染 + 代码高亮（`docs\个人知识库系统 PRD.md` §二；`docs\门户布局与功能改造需求文档.md` §8）。
- 目录树层级（`parentId`/`sortOrder`）、拖拽排序/移动、`⋯` 菜单（编辑/置顶/🔒权限设置/删除）、移动到点选（门户文档 §14）。
- **目录树批量模式（2026-10-14，仅站主）**：目录树顶部「☑ 批量」切换 → 每行显示复选框 + 工具条 `已选 N 项｜全选本层｜清空｜批量移动｜批量删除｜退出`（退出自动清空选择，日常不显示复选框）。**批量删除 = 级联软删除**（选中项连同全部子孙进回收站、可恢复，确认弹窗明示「将删除 N 篇（含 M 篇子文档）」，不提供彻底删除）；**批量移动**用可搜索层级下拉选目标（含「顶层」，展示完整路径如 `技术笔记 / Vue`，仅未删除项，可关键字过滤 / 清空），不能移动到自身或自己的子孙下（**服务端校验**），分类不变、同级追加末尾、子孙自然跟随。选择语义：勾选父节点时其子孙显示「随父级处理」并禁止单独勾选（避免重复计数）；「全选本层」= 当前层级的可见兄弟节点。详见门户文档 §14.1/§15。
- 分类路径树（`技术/前端`）、批量归类、新增分类（PRD §二；门户文档 §14）。
- 回收站：软删除（`deletedAt`）→ 恢复 / 彻底删除 / 清空（PRD §二；门户文档 §14）。
- 评论：发表 / 删除（作者本人或 admin）；全站最新评论（门户文档 §14；**C：无专门需求文档**）。
- 封面图上传（站主，base64 ≤5MB，`/uploads/<file>` 静态托管）（门户文档 §14）。
- 浏览计数（访问 +1，公开接口，不可见文章不计数）（门户文档 §6 N10）。
- 文章可见性：四级（public/login/groups/private）+ 父子递归同步（self/same/all）+ 批量设置（`docs\用户组与内容可见性权限需求文档.md` §4）。
- **详情页就地编辑 · 无模式（2026-10-16，完善⑧；替代完善⑦的「阅读态 / 编辑态」切换）**：站主打开文章详情 → 正文**始终**是可直接编辑的文档（飞书 / Notion 式，点哪改哪），**没有「编辑页」概念、无视图切换、无弹窗**——`ArticleDetail.vue` ↔ `ArticleEditView.vue` 的两态切换取消（站主侧只有 `ArticleEditView.vue` 一个常驻文档容器；非站主仍只读走 `ArticleDetail.vue`）。标题 / 正文（Vditor `wysiwyg`）/ 分类 / 标签 / 封面**全部原地可改**；正文以 Markdown 原文落库，与阅读端 `markdown-it` 共用同一份数据契约（不引入 HTML 存储）。**编辑外壳随焦点显隐**：焦点在文档内（或点容器内任意处）→ 显示 Vditor 工具栏 / 底部状态条 / 字段控件外观；**点击文档区外（`pointerdown` 落在容器外）或 `Esc` → flush 自动保存并收起外壳**（正文仍完整呈现，编辑器**不重挂载**、不丢光标历史）；`focusout` 只认「焦点移交给容器外可聚焦元素」（`relatedTarget` 为空**不**收起——Vditor 重渲染会整体替换可编辑元素导致焦点瞬时掉落）。**进入详情 ≠ 开始编辑**：只聚焦 / 只点击不输入**不产生 PATCH**（沿用自动保存的 unchanged 指纹短路）。**两态零布局跳动**：外壳收起时按**实测工具栏高度**给编辑区占位（`--ikit-toolbar-h`）+ 底栏定高槽，实测两态下容器 / 正文的宽高、内边距、相对偏移完全一致。字段在非聚焦 / 非悬停态以**静态文本**样式呈现（透明边框 + 透明底色，几何不变），悬停或聚焦即出现输入控件外观。
- **新建文章 = 同一详情容器内的空白文档（完善⑧）**：左栏「✎ 新建文章」与目录树「＋ 新建子文档」都进入**同一个常驻文档容器**（后者保留 `parentId`），空文档即聚焦（自动展开编辑外壳并把光标放进正文）；**首次自动保存即创建**（`POST`，`status:'draft'`），成功后同一容器继续编辑（不重挂载 → 不丢正在输入的内容）。
- **自动存草稿 + 手动发布/撤回（完善⑦）**：编辑过程自动保存（防抖 2s + 最大等待 10s、失焦 / 切标签页 / 离开编辑态 / `Ctrl+S` 立即落盘、失败指数退避重试、保存状态可见）；「发布」把草稿转为已发布，「撤回」退回草稿（双向）。
- **草稿仅站主可见（方案 X，完善⑦）**：`status='draft'` 的条目对非 admin 在读路径（列表 / 搜索 / 分类计数 / 评论 / 详情 / 浏览计数 / Agent 检索）一律不可见；开关 `KB_DRAFT_VISIBILITY=admin-only|everyone`（默认 `admin-only`，`everyone` 即回滚为「草稿全员可见」）。存量历史草稿在启动时**幂等一次性迁移**为已发布（写前自动备份、`db.meta.draftPublishV1` 标记、`KB_MIGRATE_DRAFT_STATUS` 开关）。
- **⚠️ 发布前必做（完善⑦）**：校正 `packages\plugins\knowledge\src\migrate.ts` 的 `DRAFT_PUBLISH_CUTOFF` 为**真实上线时刻**（否则窗口期内新建的真实草稿会在下次启动被自动发布 → 游客可见）。该常量是存量迁移的截止时间护栏（只改判 `createdAt < cutoff` 的历史 `draft`），改动属**数据迁移变更，需评审**；发布说明中记录校正值与执行时间。
- 批量导入文档：站主把本地 `.md`/`.markdown`（多选文件或整个文件夹）一次性导入为文章；子目录 → 分类路径、顶层目录 → 标签（门户文档 §16；**已恢复 2026-10-13**）；**导入条目默认 `status:'published'`（导入即可见，完善⑦）**。
- 批量导入支持**选择 / 新建父文档**（2026-10-13）：导入弹窗「导入到」区块默认「顶层（无父文档）」，可搜索层级下拉（完整路径 `技术笔记 / Vue / 组件`）选定挂载父档，可一键清空回顶层；「＋ 新建父文档」可设标题 + 分类 + 可见性（四档，`groups` 时多选用户组）并**自动选中**为新父级（门户文档 §16）。
- **文章互链跳转（2026-10-15）**：正文支持两种内部文档链接语法，点击即**同页切换**到目标文章：
  - `[[文章标题]]`（wiki 式，**按标题**解析，忽略大小写与空白差异）；
  - `[文字](ikit://doc/<id>)`（**按 id** 解析）。
  解析目标必须存在于「**当前用户可见的文章索引**」（`GET /api/knowledge/entries?limit=1000` + 鉴权头）；**不存在 / 不可见 / 草稿对非站主不可见** → 渲染为**失效链接**（虚线 + 弱化色 + tooltip「文档不存在或无权访问」），点击**不跳转**并 toast 同文案。**同名多篇**（2–5 项）弹出轻量内联选择列表（标题 + 分类/父路径），可取消（不跳转）。**返回栈**：由正文互链进入的跳转逐篇压栈，详情页「返回」在栈非空时为「← 返回上一篇」（弹栈回上一篇），栈空时为「← 返回列表」；从卡片流 / 目录树 / 归档 / 回收站等**外部入口**进入文章会清空该栈。顺带修正：外部 `http(s)` 链接补 `target="_blank" rel="noopener noreferrer"`（新标签打开，不再离开当前页）；页内锚点 `#xxx` 在详情容器内**平滑滚动**到匹配标题（优先按渲染生成的 `heading-N` id，未命中则**按标题文本**匹配、忽略大小写与空白），并阻止默认 hash 跳转。
- **编辑端互链辅助（2026-10-15）**：Vditor 工具栏新增「**插入文档链接**」按钮 → 打开**可搜索选择器**（按标题过滤 + 展示分类/路径），选中即插入 `[标题](ikit://doc/<id>)`（标题含 `[` `]` / 换行等特殊字符时自动转义；插入文本优先 `[[标题]]`，标题不安全时退回 id 式）；输入 `[[` 触发**标题自动补全**（Vditor 官方 `hint` API，候选带分类/父路径）。编辑器与阅读端共用同一份可见文章索引（见实现位置）。
- **飞书文档式可视化编辑（2026-10-15）**：编辑器从 Vditor `ir`（即时渲染，仍显示 `#` / `**` 等语法标记）升级为 **`wysiwyg`（富文本所见即所得，不显示任何 Markdown 语法标记）**，底层**仍以 Markdown 存取**（`getValue()` = `lute.VditorDOM2Md`，`readValue()` / 自动保存 / 互链 / 导入流程口径不变）。在 Vditor 公开 API 与工具栏事件之上补齐**飞书式增强**（均为自建，Vditor 无内建）：
  - **① 选中文字悬浮格式条**：选中文本即浮出「加粗 / 斜体 / 删除线 / 行内代码 / 链接 / 文档互链」，动作经派发 Vditor 工具栏的 CustomEvent 完成（与点工具栏等价，**不破坏撤销栈**）；点击浮条不抢焦点（`mousedown` 阻止默认）以保留选区。
  - **② 行首 `/` 斜杠命令菜单**：空块行首键入 `/` 弹出自建菜单（16 条命令，按查询串过滤，支持拼音/英文关键字、↑↓ 选择、Enter 确认、Esc 关闭并清除已输入的 `/query`）。**刻意不复用 Vditor `hint`**：hint 的语义是「把候选插到光标处」，与「删除 `/xxx` 再插入新块」不同。
  - **③ 块手柄 + 块菜单**：悬停任意顶层块，其左侧出现手柄 → 点击展开块菜单：**上移 / 下移 / 复制 / 删除 / 转为**（正文、H1–H3、无序/有序/待办、引用、提示块 callout、代码块）以及**表格增删行列**（表格块内悬停时追加）。结构操作全部在 **Markdown 层**完成（`readValue()` → 纯函数 → `setValue()`），不直接改写 Lute 渲染出的 DOM。**真正的「按住拖拽块」未实现**（Vditor 无公开块拖拽 API，硬搬 DOM 会破坏 `data-marker` / `<wbr>` 光标协议）→ 用块菜单的「上移/下移」等价完成。
